# Многопользовательская игра "Змейка"

Сетевая многопользовательская игра "Змейка" с peer-to-peer архитектурой.
Реализована в рамках лабораторной работы по сетевому программированию.

## Описание

Игроки управляют змейками на общем игровом поле, поедают еду и растут.
Цель — набрать максимум очков, избегая столкновений с другими змейками и границами своего тела.

Особенности:
- Топология "звезда" с центральным узлом (MASTER)
- Автоматическая передача роли MASTER при отказе
- Обнаружение игр через multicast
- Отказоустойчивость через механизм DEPUTY

## Требования

- Go 1.21+
- Fyne v2 (UI framework)

## Usage

```
go run cmd/main.go
```
